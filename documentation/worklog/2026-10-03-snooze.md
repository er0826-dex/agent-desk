# 2026-10-03 — Snooze a session (`s`)

**Ask:** "I need a way to snooze sessions with set times." Eric wanted the desk
layer: the session drops out of view and comes back at a time, like mail snooze.
Not an in-session timer (Claude Code's CronCreate can do that, but it dies with
the session and is invisible from the list).

**What existed:** `u` cycles none → unread → parked red → parked blue, a manual
marker persisted in `tool_data`; nothing ever changed a flag but the key. The
td.md follow-up "auto-return on wake?" had been noted twice.

## Design

- `session.FlagSnoozed` appended as the fifth flag value; `Instance.SnoozeUntil`
  beside it, persisted as `snooze_until` (unix) in the `tool_data` blob. No
  schema migration.
- `session.ParseSnooze(spec, now)`: durations (`30m`, `2h`, `1d`, `1w`), clock
  today-or-tomorrow (`7am`, `7:30pm`, `19:00`), `tomorrow [clock]`,
  weekday `[clock]` (next occurrence, strictly after today), `m/d [clock]`
  (next year if the date has passed; today's date with a past clock is an
  error, not next year). Day-only entries wake at `DefaultWakeHour` = 7.
- `SnoozeDialog` (`s` key): the six presets from `session.SnoozePresets`, each
  showing its resolved time, plus a free-text row. Typing on a preset row jumps
  to the text row. A preset that fails to parse (e.g. "Tonight" after 7pm
  resolves to tomorrow 7pm, so it never does) would drop into the text row with
  the spec filled in.
- Wake: `wakeDueSnoozes` at the top of the `tickMsg` handler, every 2 s,
  outside the user-activity gates (in-memory, cheap). Due → `FlagUnread`,
  time cleared, one `saveInstances`. **Grouping untouched**, per the Shift+M
  decision not to fight manual grouping. Auto-return from Inactive is a
  possible second step if the marker alone is too quiet.
- Cancel: `u` (Next from snoozed lands on none, time cleared) and attaching
  (which already clears markers).
- Row: red dot, dim red title, ` zz <when>` badge in dim text —
  `3:15p` today, `Mon 7a` within the week, `10/12 7a` beyond.
- Attached `Shift+Left`/`Shift+Right`: `SessionFlag.IsSkipped()` = red parked
  or snoozed; blue and unread remain reachable.

## Second pass (same evening)

Eric, after trying it: *"Move them to a snoozed group down below and put a
little clock emoji if we know the time they're gonna come around, or a little
calendar if it's more than a day out. Instead of the little red dot."*

- `session.SnoozedGroupPath` = "Snoozed", created by the first snooze through
  `MoveSessionToGroup`, pinned last in `rebuildGroupList` (root-level check
  before the Order/Name compare), deleted again when empty.
- `Instance.SnoozeFromGroup` persisted as `snooze_from_group`. Set on first
  snooze, kept on re-snooze. Wake and both cancels (`u`, attach) call
  `returnFromSnooze`: move back only if still in Snoozed (a manual move out is
  respected; a lost or self-referential origin falls back to the default
  group), then drop the empty group. This replaces the first pass's
  "grouping untouched" decision; Eric's call, and the thing he actually
  wanted the group for.
- Icon: ⏰ if the wake time is today's calendar day, 📅 otherwise
  (`session.SnoozeWakesToday`), matching the badge's own today/day split.
  Both are 2 cells wide in lipgloss, so `renderSession` drops the separator
  after a wide status icon. A test pins the width assumption.
- Title style `SessionTitleSnoozed` (dim text, not red); badge drops the
  `zz`.

## Third pass (10/12, 1am)

Eric: *"it needs to be more intelligent … I can't type in something to
start … I don't love the suggestions, and the last item, which I then have to
hold all the way down to get to, is where I can freeform it."*

- The field is first and focused on open; what Enter will do shows under it
  live (`→ Mon 9:00am`, or the parse error after Enter).
- `session.SnoozeSuggestions(now)` replaces the fixed presets: a candidate
  pool anchored to today/tomorrow/weekday (this morning 9, lunchtime 12,
  this afternoon 2, end of day 5, tonight 8, tomorrow 9/2/7, Monday 9,
  Saturday 9, next week), the first six still ≥30 min ahead, duplicate
  instants folded (Sunday's "Monday morning" is "Tomorrow morning").
- Typing narrows the list by label substring; `↓` walks it, `↑` past the
  top or any typed key returns to the field. Enter: highlighted row; else the
  first row still matching (the on-screen list wins over a bare parse of
  "tomorrow"); else the typed text parsed.
- `DefaultWakeHour` 7 → 9 so typed day words land on the same morning as the
  suggestions.
